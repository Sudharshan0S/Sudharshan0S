### 🧬 02. NeuroScan AI
**Deep Learning | Medical AI Research Prototype | Explainable AI**

A brain CT classification prototype that predicts **Normal, Ischemic, or Hemorrhagic** categories and displays class probabilities alongside Grad-CAM heatmaps.

**Key Engineering Highlights**
- 🧠 ResNet50V2-based image classification.
- 🔍 Grad-CAM visualizations to inspect image regions influencing predictions.
- 🔌 React frontend connected to a FastAPI inference backend.
- 📈 Reported held-out test accuracy: **90.3%**.
- 📊 Reported macro-F1: **0.847 on 934 CT slices**.

**Technology Stack**
